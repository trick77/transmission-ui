Row actions and the context menu

Three changes, shown against the current row. The actions get a column of their own after Name, the inline pause button folds into the context menu, and the trigger stays visible at every width instead of appearing on hover.

1 · What it does today current

.acts is position:absolute; right:0; opacity:0, lit only on :hover, sitting on a gradient that fades out whatever column it covers. So the controls hide the Path cell underneath, they are invisible until the pointer arrives, and on a touch screen there is no hover event at all, which leaves them unreachable. The first row below is drawn in its resting state, the second on hover.

resting — no affordance at all, and Path reads to the edge
:hover — the controls appear and mask the end of Path

2 · A column of its own proposed

A 40px grid column right after Name. Nothing overlaps, nothing fades, the glyph is always present and merely dims: --ink-3 at rest, --ink-2 on row hover, full ink while its menu is open. Pause is gone from the row; it lives in the menu, one click away, where Resume, Verify and Remove already are.

column after Name — every row reachable, Path intact

The grid pairing matters here: the compact row goes from 11 children to 12, so grid-template-columns and the matching >:nth-child(n+N){display:none} both move, or the leftover cells wrap into an implicit second row and double the row height.

3 · Narrow and touch proposed

Below the breakpoint the tail columns drop as they do now, but the actions column is never one of them. It is the only route to Pause and Remove without a right-click, so it survives every other column. On a coarse pointer the button grows from 24x22 to 40x40.

narrow — Ratio, Seeds and the dates drop, the trigger stays
coarse pointer — 40px target

4 · The menu, with Pause folded in

Unchanged from today except that it is now the only home for Pause. Remove and Remove-and-delete stay two separately worded entries, and Remove-and-delete keeps the first slot with ⌫.

Pause sits first, where the eye lands, and carries its ␣ shortcut so the keyboard path stays discoverable after the button is gone. A stopped torrent shows Resume in the same slot.
